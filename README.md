One word, 11 characters: **kummerspeck** — German "grief-bacon", the weight gained from eating through sorrow. A judge model compares the words two at a time on which is more interesting; surprise, vividness and a spark of wit beat safe filler. The field of 259 is flooded with petrichor (about 31 entries) and defenestration (about 21), so the expected picks are the least surprising words in the room — this one is unguessed, vivid, and its joke is built into the compound itself. This program writes that one word to /output/entry.txt.

## Run it

```sh
python3 main.py
```
